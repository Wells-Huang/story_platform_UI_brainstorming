# 故事星圖 UI Mockup

這是一個依據 `userstory_grilled.md` 建立的靜態 open-design 原型。可直接用瀏覽器開啟 `index.html`，不需要安裝套件或啟動 build。

## Mockup 範圍

- 前台課程探索與課程詳情
- 手動授權 / 課程級播放權限資訊呈現
- 會員「我的課程」與故事播放器，播放器不假設每個音檔都有單集圖片
- 後台內容管理、批次 MP3 上傳、會員權限、會員篩選與操作紀錄
- 手機直向使用版面：底部導覽、播放器優先、音檔清單以章節與狀態呈現
- 需求中的關鍵狀態：`published`、`hidden`、`draft`、`ready`、`processing`、`active`、`restricted`、`grant_pending`

## 檔案

- `index.html`：主要 UI 結構
- `styles.css`：視覺設計與響應式版面
- `app.js`：畫面切換、篩選、播放器與批次上傳 mock 互動
- `assets/story-worlds-hero.png`：故事平台視覺素材
